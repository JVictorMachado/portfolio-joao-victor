# Portfólio João Victor

Portfólio pessoal desenvolvido em HTML, CSS e JavaScript, sem dependências.

## Executar

Abra `index.html` no navegador. Mantenha `profile-source.png` na mesma pasta.

## Publicar na Cloudflare Pages

Conecte este repositório ao Cloudflare Pages. Selecione nenhum framework, deixe o comando de build vazio e use `.` como diretório de saída.

## Recursos

- Layout responsivo
- Filtros de projetos
- Links para GitHub e LinkedIn
- Contato e cópia do endereço de e-mail
